Zing

A fast, native Azure Storage emulator written in Zig. Drop-in replacement for Azurite with dramatically better throughput and latency.

GitHub → Quick Start
terminal
$ git clone https://github.com/teilin/zing.git
$ cd zing && zig build
$ ./zing
info: Zing blob service listening on port 10000
info: Zing queue service listening on port 10001
info: Zing table service listening on port 10002
Why Zing?

Built for speed, from the ground up

Azurite is built on Node.js/TypeScript — GC pauses, event-loop bottlenecks, and JS crypto overhead. Zing is different.

⚡

Native machine code

No runtime, no GC, no JS VM overhead. Just bare-metal x86_64 performance from Zig's zero-cost abstractions.

🔌

epoll I/O

10k+ concurrent connections with epoll (Linux) — handles burst traffic without the event-loop backpressure of Node.js.

📦

Single static binary

No Node.js, no npm, no virtualenv. One file to download, one command to run. Under 2 MB compressed.

🔧

Arena allocators

Bulk memory management with zero per-request malloc overhead. Predictable latency even under load.

Supported Services

Blob, Queue, and Table — one binary

All three Azure Storage services run simultaneously on separate ports from a single process.

ServicePortCapabilitiesStatus
Blob Storage 10000 CRUD, block/append/page blobs, copy, leases, snapshots, ACLs, RA-GRS ✅ Complete
Queue Storage 10001 Create/list/delete queues, put/get/peek/clear/update/delete messages ✅ Complete
Table Storage 10002 Create/list/delete tables, entity CRUD via JSON REST API ✅ Complete
Authentication

All three auth methods supported

SAS tokens, SharedKey HMAC-SHA256, and OAuth Bearer tokens. No-auth pass-through for dev mode.

✓ SAS (Shared Access Signature)
✓ SharedKey HMAC-SHA256

Quick Start

Get running in 30 seconds

Build from source with Zig 0.16.0, then start all three services with one command.

# Build
git clone https://github.com/teilin/zing.git
cd zing
zig build

# Run all services
./zig-out/bin/zing

# Create a container and upload a blob
curl -X PUT "http://127.0.0.1:10000/devstoreaccount1/mycontainer?restype=container"
curl -X PUT -d "Hello!" "http://127.0.0.1:10000/devstoreaccount1/mycontainer/myblob.txt"
curl "http://127.0.0.1:10000/devstoreaccount1/mycontainer/myblob.txt"
# → "Hello!"
Architecture

Clean module layout

Pluggable storage backends, generic epoll server, and per-service routers.

zing/
├── src/
│ ├── main.zig           # Entry + CLI + triple-server startup
│ ├── http/              # epoll server + blob router + request parser
│ ├── queue/            # QueueStore + QueueRouter
│ ├── table/            # TableStore + TableRouter (JSON)
│ ├── auth/             # SharedKey + SAS validation
│ ├── storage/          # FileBackend + MemBackend + ExtentStore
│ └── xml/              # XML serialization/deserialization
└── docs/               # Development diary + design prompt
